Product

WCI

Open-source infrastructure security and cloud automation platform, designed to help teams build, secure, automate and deploy cloud infrastructure. WCI analyzes infrastructure configurations and changes to identify security risks, understand permissions and exposure, map attack paths and explain the real-world impact of changes.

It goes beyond finding problems: the platform is designed to automate parts of the infrastructure lifecycle, from configuration and security validation to deployment and ongoing monitoring.

WCI initially focuses on Terraform and OpenTofu, with cloud infrastructure and GitHub and CI/CD workflows as its foundation.

What WCI aims to provide

Infrastructure security scanning

Identifies misconfigurations and security weaknesses.

Change and PR analysis

Shows what a code change does to the security posture.

Permission and access analysis

Shows who can access what, and how permissions affect risk.

Attack-path analysis

Maps paths from exposed systems, identities or compromised resources to sensitive infrastructure.

Security explanations

Turns complex infrastructure changes into clear, actionable information.

Infrastructure automation

Automates repetitive configuration, validation and security tasks.

Cloud deployment automation

Supports secure, repeatable deployment workflows.

CI/CD integration

Brings security and infrastructure checks into development and deployment pipelines.

Continuous security awareness

Tracks how infrastructure security changes over time.
